# 📊 Electrolytix

An end-to-end data analytics project that transforms electronics sales data into actionable insights on **revenue, product performance, customer purchasing behaviour, regional performance, and sales trends**.

The project demonstrates a complete analytics workflow using **Python, Pandas, SQL/MySQL, and Power BI**, from data cleaning and transformation to analytical querying and interactive business dashboards.

---

## 🎯 Objectives

* Analyze revenue and sales performance across products and categories
* Identify top-performing products and major revenue contributors
* Analyze customer purchasing and order patterns
* Evaluate regional sales performance
* Track revenue and sales trends over time
* Develop KPI-driven dashboards for business decision-making
* Generate actionable insights from sales data

## 🧹 Data Preparation

The dataset was cleaned and prepared before analysis by:

* Removing duplicate and invalid records
* Handling missing values
* Validating order and sales fields
* Standardizing date formats
* Handling missing product prices
* Creating derived revenue metrics
* Creating Year, Month, and Month Name fields

---

## 🔍 SQL Analysis

SQL was used to transform and analyze the cleaned dataset.

Key analysis included:

* Revenue aggregation
* Product performance analysis
* Category-level sales comparison
* Regional performance analysis
* Monthly revenue analysis
* Units sold analysis

SQL views were created for reusable reporting, including:

* `Monthly_Revenue`
* `Product_Performance`
* `Region_Performance`

---

## 📊 Power BI Dashboard

The interactive dashboard provides:

* **Total Revenue**
* **Total Orders**
* **Average Order Value**
* Revenue by Product Category
* Top-Selling Products
* Regional Revenue Distribution
* Customer Purchase Trends
* Category Performance
* Revenue Trends Over Time

Interactive filtering and drill-downs allow users to explore performance across products, categories, regions, and time periods.
