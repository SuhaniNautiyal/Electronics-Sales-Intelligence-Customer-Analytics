# 📊 Electronics Sales Analysis Dashboard

## 📖 Project Overview

The Electronics Sales Analysis Dashboard is an end-to-end data analytics project designed to transform raw sales data into actionable business insights. Using Excel, SQL, and Power BI, the project analyzes product performance, revenue trends, customer purchasing behavior, and regional sales patterns through interactive visualizations and KPI tracking.

The goal is to demonstrate the complete analytics workflow, including data cleaning, exploratory data analysis, SQL-based querying, and dashboard development for data-driven decision-making.

---

## 🎯 Objectives

* Analyze sales performance across different electronic product categories.
* Identify top-performing products and revenue contributors.
* Track sales trends over time.
* Evaluate customer purchasing behavior and order patterns.
* Compare sales performance across regions and categories.
* Build an interactive dashboard for business reporting and decision support.
